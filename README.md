# Nexus — Full-Stack CRUD System

Nexus is a full-stack web application designed to practice modern web development through a simple CRUD (Create, Read, Update, Delete) system. It combines a responsive user interface with a PostgreSQL database and authentication.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Database:** Supabase PostgreSQL
- **Authentication:** JWT Bearer Tokens

## Features

- Create, view, update, and delete records
- Modern and responsive user interface
- User authentication and protected operations
- Database integration
- Organized and maintainable project structure

## Project Goals

- Practice full-stack development
- Understand frontend and database integration
- Learn authentication and API security
- Build a portfolio-ready project using modern technologies

## Status

Currently in development.
